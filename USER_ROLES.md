### 4.1 Administrator

The Administrator has full control over system configuration, academic structure, users and institutional data.

| Module | Key Features |
|---|---|
| **User & Role Management** | Create, edit, deactivate and delete user accounts; assign roles and permissions (Admin, Teacher, Student); reset passwords and manage account status |
| **Academic Structure** | Manage faculties, departments and programs; define courses, credit hours and prerequisites; set up academic years, semesters and class sections |
| **Admissions & Enrollment** | Manage student admission records and applications; approve and monitor course registration; assign students to programs and batches |
| **Scheduling** | Create class routines and exam schedules; allocate teachers, rooms and time slots; detect and resolve scheduling conflicts |
| **Fees & Finance** | Define fee structures and payment schedules; record payments and generate receipts; track dues, waivers and scholarships |
| **Results & Records** | Review and publish examination results; generate transcripts and certificates; maintain complete academic records |
| **Reports & Analytics** | Enrollment, attendance, result and financial reports; dashboard with key institutional statistics; export reports to PDF and Excel |
| **System Administration** | Manage notices and announcements; configure system settings; view audit logs and manage data backups |

### 4.2 Teacher

Teachers manage their assigned courses, student attendance and assessments.

| Module | Key Features |
|---|---|
| **Profile & Dashboard** | View and update personal profile; dashboard with assigned courses, classes and notices |
| **Course Management** | View assigned courses and student lists; upload lecture materials, syllabus and resources; post course announcements |
| **Attendance** | Record daily attendance per class; view attendance summaries and low-attendance alerts |
| **Assessment & Grading** | Create assignments, quizzes and exams; enter and update marks within the allowed period; submit final grades for admin approval |
| **Communication** | Send messages and notices to students; respond to student queries |
| **Reports** | Class performance and attendance reports; download student lists and mark sheets |

### 4.3 Student

Students access their academic information, register for courses and communicate with the university.

| Module | Key Features |
|---|---|
| **Profile & Dashboard** | View and update personal information; dashboard with schedule, notices and pending tasks |
| **Course Registration** | Browse available courses and register each semester; view registration status and approvals |
| **Learning Resources** | Access course materials and syllabus; submit assignments online |
| **Attendance & Routine** | View class routine and exam schedule; check attendance record per course |
| **Results** | View marks, grades, GPA and CGPA; download result sheets and transcripts |
| **Fees** | View fee details, dues and payment history; download payment receipts |
| **Communication** | Receive notices and notifications; send queries or requests to teachers and administration |
