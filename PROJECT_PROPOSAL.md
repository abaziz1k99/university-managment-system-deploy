# Infinity University Management System

## Project Overview

The Infinity University Management System is a web-based prototype for organizing common university administration and academic workflows in one portal. It provides separate workspaces for administrators, teachers, and students, with a consistent interface for managing and viewing university information.

## Project Objectives

- Make academic and administrative information easier to manage and access.
- Give each user role access to the features relevant to their work.
- Demonstrate common university workflows, including registration, attendance, grading, fee tracking, and communication.

## Main Features

### Administrator

Administrators manage student admissions and records, users and roles, faculties, departments, programs, courses, semesters, schedules, fees, notices, and reports. They can review course registration requests and approve or return teacher-submitted grades.

### Teacher

Teachers view assigned courses and student lists, share course materials, record attendance, create assessments, review online assignment submissions, and submit grades for administrator approval. They can also send course announcements and respond to student queries.

### Student

Students can view their profile, schedule, notices, attendance, results, GPA/CGPA, fee balances, and payment history. They can request semester course registration, access learning resources, submit assignments, download result and fee records, and contact teachers or administration.

## Technology and Data

The prototype is built with Angular and TypeScript, using PrimeNG for interface components. Seed data and browser storage support demonstration workflows and preserve changes on the same browser.

## Project Scope

This version is intended for demonstration and academic prototyping. It uses mock authentication and browser-based storage; it does not include a production backend, institutional account integration, or live payment processing. A production deployment would require secure server-side authentication, a database, access controls, and integration with university systems.
